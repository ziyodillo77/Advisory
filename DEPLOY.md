# Mizan Advisory: Go-Live Guide

## What's in this folder

| File / folder | Purpose |
|---|---|
| `index.html`, `privacy.html` | **English source pages.** Edit text here. |
| `styles.css`, `app.js` | Design and interactive features (calculator, chat, live CBU rates, consent). |
| `i18n/ru.json`, `i18n/ar.json`, `i18n/uz.json` | Russian, Arabic and Uzbek translations. Each key is the exact English text. |
| `build.py` | Builds the finished website into `dist/`. |
| `dist/` | **The website to upload.** Never edit by hand; it is regenerated by every build. |
| `assets/` | Social-sharing image and app icons. |
| `*.bak` | Backups of the original files from before the audit. Not uploaded. |

Live addresses after deployment:

- `yourdomain.com/` English
- `yourdomain.com/ru/` Russian
- `yourdomain.com/ar/` Arabic
- `yourdomain.com/uz/` Uzbek

## 1. Before the first upload (one-time)

1. **Buy your domain.** Then open `build.py` and change this line to your real domain:
   ```python
   SITE_URL = "https://www.mizanadvisory.com"
   ```
2. **Rebuild:**
   ```bash
   python3 build.py
   ```
   It must end with `All visible strings translated.`

## 2. Deploy for free on Netlify

**Option A: drag and drop (no technical setup)**

1. Create a free account at netlify.com.
2. Open **app.netlify.com/drop**.
3. Drag the **`dist` folder** (not the whole project) onto the page.
4. You get a live link like `random-name.netlify.app`. Open it and check all four languages.

**Option B: from the terminal (Claude can do future updates for you)**

```bash
npx netlify-cli login
```
```bash
npx netlify-cli deploy --dir=dist --prod
```

**Connect your domain:** in Netlify, go to *Domain management → Add a domain* and follow the DNS instructions from your domain registrar. SSL (the padlock) is switched on automatically.

**Check Russia:** ask a contact in Russia to open the site. If it is slow, the same `dist` folder can also be hosted on a small Uzbek or European server.

## 3. Turn on free analytics (after the site is live)

1. Create the accounts:
   - **Google Analytics 4**: gives a Measurement ID like `G-XXXXXXXXXX`
   - **Yandex Metrica**: gives a counter number like `98765432`
   - **Meta Pixel** (Meta Business Suite → Events Manager): gives a Pixel ID
2. Paste the IDs at the top of `app.js`, in the `ANALYTICS` block.
3. Run `python3 build.py` and upload `dist` again.

Analytics load **only after a visitor clicks "Accept"** in the cookie banner. The banner appears automatically once at least one ID is filled in.

These clicks are recorded automatically as leads, so you can see which ads and languages bring clients:

| Action | Event name |
|---|---|
| WhatsApp click | `lead_whatsapp` |
| Telegram click | `lead_telegram` |
| Instagram click | `lead_instagram` |
| Consultation form completed | `consultation_form_completed` |

## 5. Making changes later

- **Change English text:** edit `index.html`, then run `python3 build.py`. If it reports untranslated strings, add them to the three `i18n/*.json` files (inside `"html"`), then rebuild.
- **Fix a translation:** edit the value in `i18n/<lang>.json`, then rebuild.
- **Preview locally before uploading:**
  ```bash
  python3 -m http.server 8765 --directory dist
  ```
  Then open http://localhost:8765.
- Upload the new `dist` folder (drag-and-drop again, or the `netlify-cli deploy` command).
